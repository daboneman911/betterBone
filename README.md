# RepCoach

A workout planner that runs on iPhone and Mac as an installable web app (PWA):

- **Quiz → plan.** Goal, experience, equipment, days per week, session length, and optional focus areas generate a weekly plan (full body, upper/lower, or push/pull/legs depending on days).
- **Exercise library.** 873 exercises filterable by **body part** (then by individual muscle), equipment, level, type, and name. A toggle includes exercises that hit the muscle secondarily.
- **Workout player.** Set-by-set logging with weight/rep steppers, "last time" numbers, timed holds, a rest timer with beeps, and the screen kept awake.
- **Progress.** Workouts per week, a week streak, bodyweight trend, and full history.
- **Offline.** Everything lives on the device. Works without a connection once loaded (when served over HTTPS).

No build step, no dependencies, no account, no server-side code.

## Run it locally (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```

Open <http://localhost:8080>. The server also prints a LAN address you can open from an iPhone on the same Wi-Fi.

Phone testing over the LAN has two limits:
- Plain `http://` to an IP address isn't a secure context, so offline mode and the service worker are disabled there. Everything else works.
- Windows Firewall may block the phone. Allowing `node.exe` usually needs admin rights. If you can't, use the hosted version below.

## Put it on your iPhone and Mac (free hosting with GitHub Pages)

An installed PWA needs HTTPS, which GitHub Pages provides for free. This is already set up:

- Repo: <https://github.com/daboneman911/betterBone> (public; Pages serves `main`, folder `/`)
- **Live app: <https://daboneman911.github.io/betterBone/>**

Pushes to `main` redeploy automatically (see *Updating* below). If a push ever doesn't trigger a deploy, run:

```powershell
gh api -X POST repos/daboneman911/betterBone/pages/builds
```

**iPhone:** open that URL in Safari → Share → **Add to Home Screen**. It launches full-screen like a native app and works offline.

**Mac:** Safari 17+ → File → **Add to Dock**. In Chrome, use the install icon in the address bar.

The phone and the Mac each keep their own data. Use Settings → **Export backup** / **Import backup** to move it between them.

## Updating after you change code

```powershell
powershell -ExecutionPolicy Bypass -File tools\publish.ps1 -Message "What changed"
```

The script runs the planner check, bumps `VERSION` in `sw.js`, then commits and pushes. Installed copies fetch the new files and show the update on the second launch after the deploy.

## Known limitations

- **No Apple Health.** Browsers can't access HealthKit, so steps and workouts don't sync there. That would need a native Swift app built on a Mac.
- **Timer sounds respect the silent switch** on iPhone. With the screen on, the rest timer is reliable. In the background, iOS pauses the page, and the timer catches up correctly when you return.
- **Bodyweight-only plans skip shoulders, biceps and calves.** The dataset has no beginner bodyweight exercises for those, so those slots are left out rather than filled with something unsuitable. Adding any equipment fixes it.
- **Exercise images load from jsDelivr** the first time each one is viewed, then they're cached. Text data is bundled.
- **Data is per device.** If you clear Safari's website data, it's gone. Export a backup occasionally.

## Project layout

```
index.html, styles.css, manifest.webmanifest, sw.js   app shell
js/app.js            router + boot
js/planner.js        plan generation (pure, testable)
js/store.js          localStorage state, units, backup
js/views/*.js        one file per screen
data/exercises.json  bundled exercise data
icons/               generated by tools/make-icons.ps1
tools/serve.js       zero-dependency dev server
tools/check-planner.mjs   generates plans for all 2,160 quiz combinations and flags problems
tools/build-data.mjs regenerates data/exercises.json from upstream
```

Checks:

```powershell
& 'C:\Users\X\Documents\REA\node-v24.20.0-win-x64\node.exe' tools\check-planner.mjs
```
